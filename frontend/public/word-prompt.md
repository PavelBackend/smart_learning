Я изучаю английский язык. Преврати мой список английских слов и выражений в **строгий JSON** для импорта в приложение. Сохрани на рабочий стол только JSON без Markdown, комментариев и пояснений.

Формат корневого объекта:

```json
{
  "words": [
    {
      "english": "serendipity",
      "translations": ["счастливая случайность", "неожиданная удача"],
      "examples": [
        {"en": "Finding this café was pure serendipity.", "ru": "Найти это кафе было счастливой случайностью."}
      ],
      "part_of_speech": "noun",
      "note": "Употребляется для приятной неожиданной находки.",
      "tags": ["повседневное"]
    }
  ]
}
```

Правила:

1. Для каждого корректного входного слова или устойчивого выражения создай ровно один объект. Не добавляй слова, которых нет в списке.
2. `english` — исходное слово в словарной форме. Для фразовых глаголов и устойчивых выражений сохрани выражение целиком.
3. `translations` — 1–3 распространённых русских перевода в контексте обычной речи. Они должны подходить для проверки ответа по точному совпадению после удаления регистра и пунктуации. Не добавляй слишком общие или спорные синонимы.
4. `examples` — один короткий естественный пример на английском и его точный русский перевод. Не используй личные факты обо мне.
5. `part_of_speech` — английское обозначение части речи (`noun`, `verb`, `adjective`, `adverb`, `phrasal verb` и т. п.) или `null`, если неуместно.
6. `note` — короткая полезная подсказка об оттенке значения или употреблении либо `null`.
7. `tags` — 0–2 коротких тематических тега на русском.
8. Все строковые значения должны быть корректно экранированы; JSON должен проходить `JSON.parse`. Не используй завершающие запятые.
9. Если слово неоднозначно, выбери самое частое значение и поясни выбор в `note`. Не выдумывай редкие значения.
10. Список может быть распознан с рукописных фото. Исправляй только очевидные опечатки в английских словах; строки, которые нельзя уверенно восстановить, пропускай. Не выдумывай перевод для бессмысленного сочетания букв.

Обрабатывай список порциями по 30–50 строк, чтобы JSON не обрезался из-за ограничения длины ответа.
